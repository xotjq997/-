# 설치/설정 가이드

## 전체 흐름

```
[담당자] 급여자료를 구글시트 "급여입력"에 입력
        │
        ▼
[Google Apps Script] 검증 → 간이세액표 조회로 원천세 계산 → 4대보험 계산
        │
        ▼
[Google Apps Script] 세무사랑 Pro용 연동파일(csv) 생성 → Google Drive 폴더에 저장
        │                                              "연동로그"에 상태=대기 기록
        ▼
[Google Drive for Desktop] 세무사랑 Pro가 설치된 PC로 자동 동기화
        │
        ▼
[로컬 RPA 에이전트 (Python, 해당 PC에서 상시 실행)] 새 파일 감지
        → 세무사랑 Pro 화면 자동 조작 (가져오기 or 필드 입력)
        → "연동로그"에 상태=완료/오류 기록
        ▼
[세무사랑 Pro] 원천세 신고서 작성 화면에 데이터 반영 (사람이 최종 확인 후 신고 접수)
```

핵심 이유: Google Apps Script는 구글 클라우드에서 실행되므로 사용자 PC의 데스크톱
프로그램 화면을 조작할 수 없습니다. 화면 자동입력(RPA)은 반드시 세무사랑 Pro가
설치된 PC에서 도는 별도 프로그램이 맡아야 해서, 계산은 클라우드(GAS)가, 화면 입력은
로컬 에이전트가 나눠서 담당하는 구조입니다.

## 1단계: 구글시트 + Apps Script 설정

1. 새 Google 스프레드시트를 만든다.
2. 확장 프로그램 > Apps Script 를 연다.
3. 이 저장소 `gas/` 폴더의 파일들을 그대로 Apps Script 프로젝트에 복사한다.
   (파일당 하나씩 새 스크립트 파일로 만들고 내용을 붙여넣으면 됨. `clasp`을 쓴다면
   `clasp push`로 한 번에 올릴 수 있음)
4. 스프레드시트로 돌아와 새로고침하면 "원천세 자동화" 메뉴가 생긴다.
5. 메뉴 > **1) 시트 최초 설정** 실행 → 필요한 시트가 전부 생성됨.
6. **간이세액표** 시트: 홈택스(www.hometax.go.kr) > 조회/발급 > 기타조회 > 근로소득
   간이세액표에서 최신 표를 다운로드해 그대로 붙여넣는다. (임의로 세액을 계산하는
   수식이 아니라 국세청 공식 표를 그대로 참조하는 방식이므로, 이 표가 없으면 계산이
   불가능하다.)
7. **보험료율설정** 시트: 기본값이 채워져 있지만 반드시 최신 고시 요율인지 확인한다.
   (국민연금/건강보험/장기요양보험/고용보험 요율은 매년 바뀝니다.)
8. **설정** 시트: `EXPORT_FOLDER_ID`에 Google Drive 폴더 ID를 넣는다. 이 폴더는
   세무사랑 Pro가 설치된 PC에서 Google Drive for Desktop으로 동기화되어야 한다.
9. **직원마스터** 시트에 직원 정보를 입력한다.

## 2단계: 매월 급여 처리

1. **급여입력** 시트에 이번 달 급여자료를 입력한다.
2. 메뉴 > **전체 실행 (검증→계산→내보내기)** 클릭.
   - 오류가 있으면 "급여입력" 시트에 빨간 셀+메모로 표시되고 중단됨.
   - 통과하면 "계산결과" 시트가 채워지고, "연동로그"에 새 파일이 상태=대기로 기록됨.

## 3단계: 로컬 RPA 에이전트 (최초 1회 설정 후 상시 실행)

`local-agent/README.md`를 따라 세무사랑 Pro가 설치된 PC에 설치한다. 요약:

1. Python 패키지 설치, `config.yaml` 작성.
2. `inspect_controls.py`로 세무사랑 Pro의 실제 화면 컨트롤 ID를 확인해 `config.yaml`에 반영.
   (이 저장소는 세무사랑 Pro 내부 구조를 모르므로 이 단계는 실제 프로그램을 열어본
   사람이 직접 해야 한다.)
3. `dry_run: true`로 먼저 검증 후, `watch_and_run.py`를 상시 실행 (Windows 작업
   스케줄러 등록 권장).

## 컴플라이언스 주의사항

- 원천세 신고는 법적 책임이 따르는 업무입니다. 이 자동화는 **입력 보조 도구**이며,
  최종 신고 전 반드시 담당 세무사/직원이 세무사랑 Pro 화면에서 값을 검토해야 합니다.
- 간이세액표, 4대보험 요율은 이 저장소 코드에 고정된 값이 아니라 시트에서 관리되는
  값입니다. 담당자가 매년(또는 변경 시) 최신 값으로 갱신해야 합니다.
- 자녀세액공제 추가 차감 등 세부 조정 항목은 기본값 0(미적용)으로 되어 있습니다.
  적용하려면 최신 소득세법 시행령 기준 금액을 확인 후 "설정" 시트에 직접 입력하세요.
