# 급여 → 원천세 신고 자동화

구글 스프레드시트에 급여자료를 입력하면 원천징수세액(간이세액표 기준)과 4대보험을
자동 계산하고, 세무사랑 Pro로 가져올 수 있는 연동파일을 생성한 뒤, 세무사랑 Pro가
설치된 PC에서 도는 로컬 에이전트가 화면에 자동으로 입력해주는 파이프라인입니다.

세무사랑 Pro는 공개 API가 없는 상용 프로그램이라 "완전 자동 연동"은 두 부분으로
나뉘어 동작합니다.

- **`gas/`** — Google Apps Script. 구글시트에서 실행되며 급여 검증, 원천세/4대보험
  계산, 세무사랑 Pro용 연동파일(csv) 생성을 담당합니다.
- **`local-agent/`** — 세무사랑 Pro가 설치된 Windows PC에서 실행하는 Python 프로그램.
  연동파일을 감지해 화면 자동입력(RPA)을 수행합니다.

## 시작하기

`docs/SETUP_GUIDE.md`를 참고하세요.

## 알아둘 점

- 근로소득 간이세액표와 4대보험 요율은 코드에 하드코딩하지 않고 스프레드시트에서
  관리합니다 (둘 다 매년 바뀌는 법정 수치이기 때문입니다). 최초 설정 시, 그리고 매년
  갱신 시 반드시 최신 공식 자료로 채워야 합니다.
- `local-agent`의 세무사랑 Pro 화면 컨트롤 식별자는 이 저장소만으로는 알 수 없는
  값입니다 (공개 스펙이 없음). `local-agent/inspect_controls.py`로 실제 프로그램을
  열어 확인한 뒤 채워야 동작합니다.
- 이 자동화는 원천세 신고 "입력 보조 도구"입니다. 최종 신고 전 담당자의 육안 확인을
  거치도록 설계되어 있으며, 그 확인 절차를 생략하지 않는 것을 권장합니다.
