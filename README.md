# 급여 → 원천세 신고 자동화

구글 드라이브의 "RPA_원천세" 스프레드시트에 회사별 급여자료(회사명/사업자등록번호/
이름/급여구분/금액)를 입력해두면, 세무사랑 Pro가 설치된 PC에서 도는 로컬 에이전트가
그 자료를 읽어 회사별로 세무사랑 Pro 화면에 자동으로 입력하고 마감까지 수행하는
파이프라인입니다.

세무사랑 Pro는 공개 API가 없는 상용 프로그램이라 화면 자동입력(RPA)은 반드시
세무사랑 Pro가 설치된 PC에서 도는 **`local-agent/`**(Python)가 담당합니다. 세액
계산 자체는 GAS가 아니라 세무사랑 Pro가 사원등록/급여자료입력 시점에 자체적으로
수행합니다.

## 처리 흐름

```
[담당자] 구글드라이브 "RPA_원천세" 시트에 급여자료 입력
        │  (회사명 / 사업자등록번호 / 이름 / 급여구분 / 금액)
        ▼
[local-agent] 시트를 읽어 회사별로 그룹핑
        │
        ▼
회사마다:
  세무사랑 Pro에서 해당 회사로 변경
        │
        ▼
  급여구분별로 (그 회사에 존재하는 것만, 순서대로)
    1_정규직근로자   → 인사급여_근로소득관리:       사원등록 → 급여자료입력 → 마감
    2_일용직근로자   → 인사급여_일용직근로소득관리: 일용직사원등록 → 일용직급여자료일괄입력 → 마감
    3_사업소득자     → 인사급여_사업소득관리:       사업소득자등록 → 사업소득자료입력 → 마감
    4_기타소득자     → 인사급여_기타소득관리:       기타소득자(이자배당)등록 → 기타소득자료입력 → 마감
        │
        ▼
  세무신고서류: 원천징수이행상황신고서 → 지방소득세납부서(명세서, 현재회사) → 마감
        │
        ▼
  다음 회사로 이동
        │
        ▼
[local-agent] 처리 결과를 "RPA_원천세" 시트의 "처리로그" 탭에 기록
```

## 시작하기

`docs/SETUP_GUIDE.md`와 `local-agent/README.md`를 참고하세요.

## 알아둘 점

- `local-agent`의 세무사랑 Pro 화면 컨트롤 식별자는 이 저장소만으로는 알 수 없는
  값입니다 (공개 스펙이 없음). `local-agent/inspect_controls.py`로 실제 프로그램을
  열어 확인한 뒤 `config.yaml`에 채워야 동작합니다.
- "RPA_원천세" 시트의 필수 컬럼은 회사명/사업자등록번호/이름/급여구분/금액뿐이지만,
  등록 화면에 더 많은 정보(주민등록번호, 입사일 등)가 필요하면 시트에 컬럼을
  자유롭게 추가하고 `config.yaml`의 `field_control_ids`에 매핑하면 됩니다.
- 이 자동화는 원천세 신고 "입력 보조 도구"입니다. 최종 마감/신고 전 담당자의 육안
  확인을 거치도록 설계되어 있으며, 그 확인 절차를 생략하지 않는 것을 권장합니다.
- `run_pipeline.py`는 상시 실행 프로세스가 아니라 실행할 때마다 그 시점 시트 내용을
  한 번 처리하고 끝나는 1회성 배치입니다.
